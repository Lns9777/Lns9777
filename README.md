An AI-powered portfolio generation system using a multi-stage **LangGraph pipeline**.

**Pipeline:**

```text
Content → Design → Critique → Refinement → Final Portfolio
```

**Technology:**

* Python
* LangGraph
* LLMs
* FastAPI
* React
* Flutter
* PyMuPDF
* ETL pipelines

The system transforms user information and documents into structured, polished portfolio content.

### 🧑‍💻 Enterprise AI Developer Assistant

An AI assistant designed around an **agentic RAG architecture** for developer-oriented workflows.

**Core concepts:**

```text
User Query
    ↓
Retrieval
    ↓
Context Construction
    ↓
LLM Reasoning
    ↓
Tool / Agent Execution
    ↓
Response
```

Focus areas include:

* RAG
* Agentic workflows
* Context retrieval
* LLM reasoning
* Developer assistance
* Knowledge-based responses
